## Overview

This interactive tool allows users to:

- Select a product category
- Choose a country of origin
- Enter a base price

The calculator uses category-specific tariff data to compute estimated additional costs, including:

- **Tariff percentage**
- **Extra cost added**
- **Total adjusted price**
- **Notes on retaliation, exemptions, and trade policy**

---

## Features

- **10 Product Categories**: Includes electronics, apparel, food, cars, toys, etc.
- **Dynamic Form UI**: Built using Bootstrap 5 for clean responsiveness.
- **Tariff Intelligence**: Pulls from a detailed JavaScript object (`tariffData`) with rates, examples, and notes.
- **SEO-Ready**: Open Graph, Twitter card, and meta descriptions embedded.
- **Neumorphic Navigation UI** (optional): Preps integration with the Food4Thoth styling framework.

---

## Technologies Used

- **HTML5 + CSS3**
- **Bootstrap 5.3**
- **Vanilla JavaScript**
- **Responsive meta & SEO tags**
- **Neumorphic UI components**

---

## Example Use Case

> A consumer wants to purchase a $1000 laptop from China.  
> With a 20% tariff:  
> - **Extra Cost:** $200  
> - **Total Price:** $1200  
> The app will also display China’s retaliation measures and USMCA applicability.
