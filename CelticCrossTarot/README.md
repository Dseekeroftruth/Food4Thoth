# Celtic-Cross Tarot Draw!

**Free Tarot Draw!** is a web-based tarot reading engine that generates a randomized Celtic Cross Tarot reading based on the Rider-Waite Tarot deck. Adapted and enhanced by De’Jahn and Food4Thoth, this project blends mystical symbolism with modern web design.

original source:
A Pen created on CodePen.io.  
Original URL: [https://codepen.io/kezzokay/pen/OJRjdJX](https://codepen.io/kezzokay/pen/OJRjdJX)

Link to 78 Card Sacred Geometry Enhancement: [FOOD4THOTH Celtic-Cross Tarot](./index.html).

---

## 🎶 Overview

This project provides a free tarot reading experience. When the user clicks the "Click for your reading!" button, the engine draws a randomized Celtic Cross spread, displaying tarot card images and interpretations on a beautifully styled interface. Users can also clear the results or view all cards.

---

## 🚀 Features

- **Randomized Celtic Cross Spread**:  
  - Generates a tarot reading based on the Celtic Cross layout.
  - Uses the Rider-Waite Tarot deck descriptions of imagery and symbolism.

- **Interactive Controls**:  
  - **Draw Reading**: Click to generate a new reading.
  - **Clear Results**: Clear the current display.
  - **Display All Cards**: Show all available tarot cards.

- **Mystical Aesthetic**:
  - Sacred Geometry based Tarot Cards.
  - Neumorphic navigation with quick access to related Food4Thoth projects.

- **Responsive Design**:  
  - Flexible grid layout for tarot card displays.
  - Optimized for various screen sizes.
