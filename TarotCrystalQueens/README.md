# FOOD4THOTH CRYSTAL QUEENS TAROT (18+)

# 🌌 Overview

The Food4Thoth Crystal Queens Tarot is an interactive tarot reading experience featuring an original deck designed by DeJahn and Food4Thoth. This web-based application uses GLSL shaders to create a dynamic background effect and includes features such as random card selection, detailed card descriptions, and text-to-speech integration.

---

Original Cards & Design by: DeJahn and Food4Thoth
Background Effect: Neuro Noise (GLSL Shader)
Shader Source: Ksenia K’s CodePen

## Neuro Noise (GLSL Shader)

A Pen created on CodePen.io. Original URL: [https://codepen.io/ksenia-k/pen/vYwgrWv](https://codepen.io/ksenia-k/pen/vYwgrWv).

---

# 🔥 Features

- **Interactive Tarot Reading** – Click to shuffle the deck and receive a randomized card.
- **Custom-Designed Deck** – Original artwork inspired by mystical and esoteric themes.
- **Dynamic Visual Effects** – A GLSL-based Neuro Noise shader creates a hypnotic, evolving background.
- **Responsive Design** – Optimized for desktop and mobile devices.
- **Text-to-Speech Integration** – Listen to the full description of each card.
- **Age Verification Modal** (Standalone Version) – Ensures compliance with age restrictions for explicit content.
- **iFrame-Compatible Popup Version** – For embedding within websites where age verification is already handled.

---

# 🚀 Usage

### Standalone Version (With Age Verification)

For use as an independent tarot reading application with built-in age verification.

<iframe src="./indexAge.html" width="400" height="800"></iframe>

### Open indexAge.html in a browser.

Features in this version:
- Displays an age verification modal before accessing the tarot reading.
- Once confirmed, users can interact with the deck freely.

### iFrame Popup Version (Without Age Verification)

For embedding where age restrictions are handled externally.

Differences in this version:
- 🚫 No age verification modal (designed for sites already enforcing this).
- 🎴 Full tarot functionality in a popup-friendly format.

---

# 🎴 How to Use

Interacting with the Tarot Deck
1.  Click **“Randomize”** to shuffle and select a card.
2.	Click the selected card to stop shuffling.
3.	Click **“Description”** to reveal the card’s meaning.
4.	Click **“Play Audio”** to hear the full description read aloud.
5.	Press **“Space”** or Click again to draw a new card.
