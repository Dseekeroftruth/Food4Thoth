FOOD4THOTH NEXUS — Static Site
  ================================
  All 16 games across 6 realms.

  HOW TO RUN LOCALLY
  ------------------
  Option A (Python — easiest):
    1. Open a terminal in this folder
    2. Run:  python3 -m http.server 8080
    3. Open: http://localhost:8080

  Option B (Node):
    1. npm install -g serve
    2. serve .
    3. Open the URL shown

  Option C (VS Code):
    Install the "Live Server" extension, right-click index.html → Open with Live Server

  NOTE: Double-clicking index.html won't work — the hub needs a local server.
  The games in the /games/ folders can be opened directly in a browser.
