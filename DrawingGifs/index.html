Drawing with Uploads

The Draw With Uploads page is an interactive web-based application allowing users to create digital animation artwork in real time. Users can upload sprites, illustrations, character assets, and designs and manipulate by clicking, dragging, using sliders and or using touch gestures. The app is part of Food4Thoth, a digital creative space merging art, technology, and mysticism.
