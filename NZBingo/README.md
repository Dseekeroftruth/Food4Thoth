# 🧠 Authoritarian Warning Signs Bingo

An interactive web-based satire that doubles as a serious educational tool.  
Inspired by historical scholarship and contemporary parallels, this Bingo game lets users track authoritarian tendencies in real-time—playfully, but critically.

> "Every warning sign unchecked gets us closer to the full blackout." — Libby Liberty (Game Host)

---

## 🎯 Purpose

This project is not about comparing modern regimes directly to the past. Instead, it highlights **patterns** of authoritarianism—based on works like:

- **Umberto Eco** — *Ur-Fascism*
- **Timothy Snyder** — *On Tyranny*
- **USHMM** — *Early Warning Signs of Fascism*

---

## ⚙️ How It Works

- A **5×5 Bingo board** of historical red flags
- One **FREE** center space
- Click each square as events match
- Visual feedback includes **animations** like blood splatter, masked men, cages, and nuke flashes
- Win by:
  - Completing a line (row, column, or diagonal)
  - Getting full **blackout** (all 25 spaces)

---

## 🖼️ Visual Features

- **Blood Splash**: Appears when a line is completed  
- **Masked Men Sweep**: Randomly triggered when crossing critical thresholds  
- **Cage Drop**: Symbolizes suppression or entrapment  
- **Nuke Flash**: Triggered when full blackout is reached

Animations are layered and time-based, using pure CSS and JS.

---

## 🧩 Technologies Used

- HTML5, CSS3 (Custom styling with neon/dark UI)
- JavaScript ES6+ (For game logic and animations)
- Responsive design for desktop and mobile
