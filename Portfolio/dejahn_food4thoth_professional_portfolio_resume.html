Shipped App Portfolio

Two paid games, one free game, and one free utility app — built as a solo creator and published publicly.

Neon Serpent Spiral

Paid Game · $2.99

Psychedelic point-and-explore adventure game that carries Food4Thoth’s web comics, surreal storytelling, choose-your-own-adventure systems, and musical experiments into a finished commercial iOS release.

  • 10 surreal neon worlds and 10 cosmic NPCs.
  • 25 musical minigames, Memory Fragments, artifacts, Karma, and Weirdness tracking.
  • Six endings based on exploration and player behavior.
  • Offline-first design with accessibility controls for sound, motion, CRT, and psychedelic intensity.

Pixel Quest: Retro Arcade Game

Paid Game · $1.99

Premium expanded edition built from the Terminal Game arcade architecture. Pixel Quest turns a free prototype engine into a more complete commercial product with deeper content, replay value, skins, power-ups, difficulty modes, and per-skin audio.

  • Six handcrafted skins: Old School Bit, Neon Bit, New School Kid, Pixel Kid, Wizard, Shadow Wizard.
  • Five power-ups: Speed, Invincible, 2X Score, Heart, and Eliminator.
  • Per-skin high scores, original music, haptics, and adaptive mobile layout.
  • Clear product ladder from free original to paid premium edition.

Terminal Game

Free Game

The origin project for the Food4Thoth app pipeline. Terminal Game began as a Python terminal experiment, became an HTML5 Canvas web game, and then shipped as a free iOS arcade app.

  • Prototype-to-product arc: Python terminal → Canvas web game → App Store release.
  • 8-direction movement, tap-to-move, swipe controls, D-pad controls, and continuous movement.
  • Power-ups, background music, sound effects, scoring, and quick replay loops.
  • Foundation engine for Pixel Quest’s premium expanded edition.

Glo-CALCULATO

Free Utility

Practical scientific calculator utility with a colorful Food4Thoth identity. Glo-CALCULATO proves the development pipeline can produce useful everyday software as well as games.

  • Scientific functions: sin, cos, tan, log, ln, square root, exponents, π, e, and parentheses.
  • DEG/RAD mode, scrollable history, tap-to-reuse, copy-to-clipboard, and haptic feedback.
  • Animated rainbow glow interface with friendly smiley-face launch interaction.
  • Free, privacy-forward utility with no ads, accounts, subscriptions, or in-app purchases.
