      • Interactive Rendering: Detailed ASCII art logo dynamically typed and deleted, creating a continuous flow.

    • Interactive Games: From Terminal to Cross-Platform Masterpieces

    The journey of game development began with simple terminal-based experiments and evolved into dynamic, cross-platform gaming experiences. Leveraging technologies like Python (Pygame), HTML5, CSS, and JavaScript, these projects showcase creativity, technical skills, and a commitment to engaging gameplay.

    • Stick-Figure Animations: Created engaging animations featuring stick-figure battles in Python using Pygame, complete with music and interactive movements.
    • ASCII Art Adventures: Developed terminal games featuring ASCII-based characters and environments, combining nostalgia with simple yet captivating gameplay mechanics.
    • Dynamic Gameplay: Integrated interactive prompts and evolving challenges, such as increasing enemy difficulty after specific thresholds.

    Mobile and Desktop Adaptations

    • Mobile Version:
      • Optimized for touch inputs, allowing players to navigate and interact seamlessly.
      • Improved user interface for smaller screens, ensuring accessibility and enjoyment on the go.
    • Desktop Version:
      • Added support for keyboard controls (arrow keys, W/A/S/D) and mouse clicks for precise gameplay.

    • Game Features:
      • Dynamic Enemy Mechanics: Enemies adapt to player progress, increasing in speed and quantity after collecting certain items.
      • Power-Ups: Included speed boosts, invincibility, and score multipliers to enhance gameplay depth.

    HTML5 Terminal Game

    • Purpose and Functionality: Built an interactive, retro-style terminal game in HTML5, CSS, and JavaScript, featuring grid-based gameplay where players collect treasures and avoid enemies.
    • Key Features:
      • Player Movement: Arrow keys, W/A/S/D, or touch inputs.
      • Power-Ups: Speed boost, invincibility, and score multipliers.

      • Retro visuals with monospace fonts and bright color highlights.
