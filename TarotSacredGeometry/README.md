# Sacred Geometry Tarot

## by De’Jahn & Food4Thoth

A digital Tarot experience infused with the mysticism of sacred geometry and interactive technology. This project fuses ancient esoteric wisdom with modern web-based interactivity, creating a dynamic tool for introspection and divination.

---

# Overview

The Sacred Geometry Tarot is an interactive, web-based Tarot reading experience featuring:
- A randomized card draw system for intuitive divination.
- Dynamic GLSL Neuro Noise Shader background for a hypnotic, ever-evolving visual aesthetic.
- Neumorphic UI design for an immersive and modern Tarot interface.
- Audio-enhanced readings, enabling spoken interpretations of each card.
- Expandable navigation system, allowing integration with other Food4Thoth projects.

---

## Key Features

1. **Interactive Tarot Readings**      
	•	Users can randomly draw a card from the 78-card Tarot deck.      
	•	Each card has a brief description and an option to expand for a full reading.      
	•	A text-to-speech system reads the card’s meaning aloud for a more immersive experience.      

2. **Unique Visual Aesthetic**      
	•	Neuro Noise Shader (GLSL) Background:      
	•	Adapted from Ksenia K’s CodePen.      
	•	Dynamically shifts, creating an otherworldly, fluid motion.      
	•	Neumorphic UI Design:      
	•	3D-inspired button aesthetics.      
	•	Soft shadows and highlights for a futuristic, tactile feel.      

3. **Audio-Enabled Readings**      
	•	Each card’s description can be read aloud using Web Speech API.      
	•	Built-in pause & resume functionality for the spoken interpretations.      

4. **Customizable & Expandable**      
	•	Modular card database allows easy additions or modifications.      
	•	Expandable menu system connects Tarot with other Food4Thoth applications:      
	•	Community Garden Directories      
	•	Sound & Voice Visualizers      
	•	Anarchy & Esoteric Archives      
	•	Hashisheen Album Reviews     
	
---

# Technology Stack
- HTML, CSS, JavaScript: Core framework for interactivity.
- GLSL Shader: Procedural background rendering.
- Web Speech API: Enables audio readings of card descriptions.

---

# Usage
- Click Randomize to shuffle and draw a Tarot card.
- Click on the image to stop shuffling.
- Click Show Description for a brief meaning.
- Click Full Description to load the detailed card interpretation.
- Click Play Audio to hear the reading.
