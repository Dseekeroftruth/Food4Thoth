# 🎬 Reel Reflections – Favorite Movie Personality Finder

**Reel Reflections** is a poetic, symbolic, and generational film analyzer that reveals what your favorite movie says about your soul. Built by **DeJahn** and **Food4Thoth**, it offers a dynamic interface with search functionality, speech synthesis (TTS), rich styling, and generational estimates based on film resonance.

---

## ✨ Features

- 🔍 **Movie Search** by title with live suggestions
- 🧠 **Personality + Symbolism Analysis** for each movie
- 📜 **Quote + Birth Year Estimate**
- 🗣️ **Text-to-Speech (TTS)** controls with:
  - Voice selection dropdown
  - Start / Pause / Resume / Stop functionality
- 📋 **Copy to Clipboard** button for full analysis
- 🎞️ **IMDb & Rotten Tomatoes** search links
- 🔠 **A–Z Rolodex Navigation**
- 🌀 **Smooth scroll buttons** to top/bottom
- 📬 **Suggestion Form** for unlisted favorites (via Formspree)
- 🤖 **GPT Link** to custom AI insights for ChatGPT Plus users

---

## 🛠 Technologies Used

- **HTML5 / CSS3 / JavaScript**
- **SpeechSynthesis API** for browser TTS
- **Formspree** for movie suggestion submission
- **Responsive UI** with dark neon styling + neumorphic elements
