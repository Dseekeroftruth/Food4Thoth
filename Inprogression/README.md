# INPROGRESSION - Complete Music Collection

## Overview

**INPROGRESSION** is a dynamic fusion of music and visual artistry, blending rock, funk, hip-hop, punk, and experimental sounds. This web project serves as a music library and interactive player, allowing listeners to explore **INPROGRESSION’s discography** through audio tracks, videos, and digital downloads.

This project is built using HTML, CSS, Vue.js, and various interactive elements to enhance user experience.

---

# Features

## 🎵 Music Library & Audio Player
- Full discography available for streaming.
- Vue.js-powered dynamic track list.
- Play, pause, restart, and show track details.
- Filter by album for easy navigation.

## 🎨 Visual Experience
- Integrated album artwork, music videos, and GIFs.
- Interactive Vue.js-based image slider for dynamic visuals.
- Embedded YouTube playlist featuring INPROGRESSION’s live performances and music videos.

## 📂 Content Organization
- Albums: “Time & Energy,” “Down The Rabbit Hole,” “Burned”
- Custom Music Tracks & Experimental Sounds
- Neumorphic Navigation Menu for structured browsing
- Expandable Sections for Projects & Community Initiatives (Food4Thoth, Artabillies, Anarchy Comics, Tarot, I Ching, etc.)

## 🛒 Digital Downloads & Support
- Direct purchase links for albums on Artabillies.com.
- Support options: PayPal, Venmo, Artabillies art purchases.

---

# 📌 How to Use

### 1. Listen to Music
- Click Play to stream tracks.
- Use the album filter dropdown to navigate specific collections.
- Click Show Details for track info (genre, release year, duration).

### 2. Explore Visuals
- Watch embedded YouTube music videos.
- Browse animated album artwork in the image slider.
- View the interactive timeline of INPROGRESSION’s music journey.

### 3. Navigate the Project
- Use the toggle menu (☰ Nav) for quick access.
- Click expandable sections for related creative projects.
- Discover additional interactive features like loop stations, synthesizers, games, and tarot readings.

### 4. Support & Contribute
- Purchase albums via Artabillies.com.
- Donate through PayPal or Venmo.
- Connect via email or social media links.

---

## 💻 Technologies Used
- HTML5 & CSS3 – Responsive layout & neumorphic UI.
- Vue.js (v2) – Dynamic track player, image slider, and interactivity.
- JavaScript (ES6) – Custom event handling, UI animations.
- YouTube API – Embedded videos for full album experiences.
