
# 🕹 Claw Machine Game (Food4Thoth Adaptation)

## 🎮 About the Project

This Claw Machine Game is an interactive arcade-style game where players use a virtual claw to grab character-based toys. Originally inspired by a CodePen project, this version has been fully adapted and enhanced by De’Jahn & Food4Thoth, incorporating:
- Mobile & iFrame compatibility
- Neumorphic UI navigation & footer
- Functional button improvements
- Gamification features:
- Timer-based challenge modes
- Celebration animations (rainbow confetti, screen melt effect)
- High score tracking
- New interactive toy collection system

---

## Original code source 

### Claw machine

A Pen created on CodePen.

Original URL: [https://codepen.io/Ma5a/pen/YPzzpep](https://codepen.io/Ma5a/pen/YPzzpep).

I'm terrible at controlling actual claw machines, so I coded my own. You can move the claw by holding down the button, and stop by releasing. The main challenge was to chain the animation required to move the claw and the arm. To simulate gravity, the toy tilts based on which part of the toy the claw grabs. The facial expression on the toys and the claw is also animated for fun.

# 🚀 Features & Enhancements

## 🎨 UI & Navigation
- **Responsive & Scalable**: Works in iFrame and mobile layouts with dynamic scaling.
- **Neumorphic Navigation**: Smooth, modern tabs for accessing different sections.
- **Fixed Footer**: Provides quick access to Food4Thoth and project links.

---

## 🕹 Gameplay & Mechanics
- **Fully Functional Claw Mechanism**: Move the claw horizontally & vertically to grab toys.
- **Toy Collection System**: Selected toys get displayed in the collection box.
- **Improved Button Interactivity**: Prevents accidental selections and enhances user feedback.

---

## 🎯 Challenge Modes
- **Free Play Mode**: No timer, just grab as many toys as you want!
- **Challenge Mode**: Race against time to collect toys.
- **Extra Challenge Mode** – If a toy is missed, it is put back into the machine! Fewer attempts, faster gameplay.

# 🎉 Animations & Effects
- **Rainbow Confetti Celebration**: Triggers when completing a challenge.
- **Screen Melt Reset Effect**: Gives a dynamic transition between game rounds.
- **Toy-Specific Celebration GIFs**: Unique animations based on collected characters.

---

## 📜 How to Play
1.	Choose a mode (Free Play, Challenge, or Extra Challenge).
2.	Use the buttons to move the claw left/right and up/down.
3.	Grab a toy by positioning the claw and pressing the button.
4.	Complete the challenge before the timer runs out!
5.	Watch your collection grow in the display area.
6.	Top your high scores and celebrate with animations!
