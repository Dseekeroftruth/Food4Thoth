Drawing with Fractals

The Draw With Fractals page is an interactive web-based application allowing users to create digital fractal-based artwork in real time. Users can generate various fractal designs by clicking, dragging, or using touch gestures. The app is part of Food4Thoth, a digital creative space merging art, technology, and mysticism.

🎨 Fractal Generation

This script generates unique fractals when you click or drag on the canvas. The image is influenced by mouse coordinates, system time, and selected parameters, making each creation unique.

  • Generate Flow Fields, Spirals, Branching Trees, Julia Sets, Mandelbrot Sets, Labyrinth Patterns, and Barnsley Ferns.
  • Each fractal responds dynamically to mouse/touch movements and real-time system calculations.

🔧 Customization Options

  • Canvas Size Selection: Choose from multiple resolution options.
  • Symmetry Control: Adjust fractal symmetry levels for unique variations.
  • Customize Fractal Elements:
    • 🌳 Tree Depth (for branching structures)
    • 🌀 Spiral Factor (for swirl effects)
    • 🔄 Iteration Counts (for Julia and Mandelbrot sets)
    • ✍️ Pressure Sensitivity (for dynamic interactions)

🖱️ Interactive Drawing

  • 🎨 Click & Drag: Draw fractals directly on the canvas.
  • 📱 Touch Controls: Mobile users can create fractals with intuitive gestures.

📷 Saving and Gallery Features

  • 💾 Save Fractals: Store generated fractal images in your personal gallery.
  • 🗑️ Clear Gallery: Option to remove saved images and start fresh.

🎞️ GIF Creation

  • 📹 Convert saved fractals into an

    animated GIF.
  • 🎛️ Adjustable settings:
    • ⏳ Frame Delay (adjust speed of the animation)
    • 🎚️ Quality (modify GIF resolution)
    • 📏 Resolution (adjust width and height)

🎨 Happy fractal drawing! 🚀✨
