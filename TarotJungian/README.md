# FOOD4THOTH - Jungian Thoth Tarot Spread

## Overview
The **Jungian Thoth Tarot Spread** is an interactive tarot reading application designed to integrate the mystical wisdom of the **Thoth Tarot Deck** with **Jungian psychology**. This project is part of **Food4Thoth**, an initiative blending esoteric knowledge, technology, and artistic expression.

---

## Features
- **Dynamic Tarot Spread**: Randomly draws and displays six tarot cards in a structured reading.
- **Interactive Descriptions**: Each drawn card comes with a short description and a full in-depth analysis.
- **Neumorphic Navigation Menu**: A modern, sleek UI design that enhances accessibility to various sections of Food4Thoth.
- **Custom Styling & Animations**: Highly designed elements, glowing buttons, and smooth transitions.
- **Gradient Background**: Dark-to-light transition enhancing mystical aesthetics.
- **Expandable Submenus**: Organized navigation structure for easy access to different sections, including Community Gardens, ARP Synths, Anarchy Comics, and more.

---

## Technologies Used
- **HTML5 & CSS3** (Structured content and custom styling)
- **JavaScript (ES6)** (Interactive elements, card drawing logic, and dynamic UI updates)
- **Bootstrap** (Responsive layout and design)
- **jQuery** (Simplifies DOM manipulation and animations)
- **CodePen Integration** (Original base forked and enhanced)

---

## Tarot Card Functionality
- **78-Card Deck**: Includes Major and Minor Arcana.
- **Random Draw Algorithm**: Ensures fair shuffling and unpredictable results.
- **Fifth Position Reordering**: The fifth drawn card is repositioned as the first in the spread for deeper insights.
- **File-Based Descriptions**: Full tarot descriptions are loaded from external `.txt` files for modular expansion.

---

## Navigation & UI Enhancements
### **Navigation Menu**
- **Toggle Button**: Expands the main navigation.
- **Neumorphic Tabs**: Soft UI elements for an aesthetically pleasing experience.
- **Submenus**: Categorized by topics, such as Tarot, Community, Music, and more.

---

### **Styling Enhancements**
- **Glowing Buttons**: Highly visible and interactive.
- **Text Outlining & Shadows**: Bold and defined text for readability.
- **Gradient Backgrounds**: Black to white for mystical ambiance.
