Ember Below: Sunroot Descent
================================

Standalone HTML/CSS/JavaScript roguelite.

How to play:
1. Open index.html in Safari, Chrome, or any modern browser.
2. On the grid, tap a tile row. The game randomly lands on one open tile in that row.
3. On desktop, hover a row to see odds. On iPhone, tap directly; the row roll still happens.
4. Clear enough tiles to unlock the exit.
5. Deposit coins in bucket tiles to save them as permanent surface coins.
6. Use surface coins to unlock heroes and upgrades.
7. Use Sun Power when charged to break the row rule and choose any tile.

Included features:
- iPhone-safe touch controls
- 4x4 luck-grid floors
- row odds / probability display on desktop hover
- chest, strawberry heal, trap, enemy, statue, shop, fishing pool, bucket, ember tiles
- stat-check combat
- enemy strong/easy/death animation states
- special boss floor with boss HP
- consumable inventory
- stone teeth modifiers
- permanent surface upgrades with localStorage save
- unlockable characters
- psychedelic hand-crafted visual direction

No build step required.
