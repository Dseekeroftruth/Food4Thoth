# 🧠 MINDMELT — Psychedelic Experimental Art Portal

---

# 🌈 Overview

MINDMELT is a fully immersive, web-based psychedelic art experience that invites users into a surreal vortex of visuals, illusions, glitch aesthetics, and looping animations. It’s part of the FOOD4THOTH universe, merging art, technology, and mysticism into a gallery of experimental multimedia.

# 🎨 Features
- Glitch Hero Section: Animated glitch text layered over parallax backgrounds.
- Neumorphic Navigation: Expandable side-menu system with direct access to dozens of Food4Thoth subprojects.
- Image Slideshow: Scrollable psychedelic gallery with hover effects and transitions.
- Embedded Video Gallery: Collection of YouTube and Facebook videos that loop, melt, and inspire.
- Parallax Scrolling: Layered depth sections simulating movement and illusion.
- Custom Fonts & Color Waves: Uses Syne Mono with animated background gradients to create a living canvas.
- Responsive Design: Mobile and desktop optimized for all resolutions.

---

# 🧪 Themes & Philosophy

MINDMELT is built on the philosophy of creative disruption — a playground for the senses that challenges perceptions, offers altered-state aesthetics, and explores:
- Surrealism & Graffiti
- Playfulness in Code
- Visual Noise & Flow
- Homage to Glitch Culture & Psychedelia
- Nonlinear Exploration

It’s both a gallery and a celebration of the art-mind continuum.
